## Descubierto de paso

- **Si crear el enlace falla, el correo sale igual** (con el enlace al dashboard): la creación va
  en un savepoint. Lo pidieron las pruebas de seguridad de S6.1, que usan una sesión simulada.
- **La columna `audit_logs.ip_address` es INET**: una IP no válida (en las pruebas, `testclient`)
  hacía fallar el registro en silencio. El canje la valida antes de guardarla, como el middleware.
- **`react-hooks/set-state-in-effect`**: leer el fragmento con `useEffect` + `setState` no pasa el
  linter; la página usa `useSyncExternalStore`, que además evita el desajuste de hidratación.
